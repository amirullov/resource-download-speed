# Измерение скорости загрузки ресурса

Консольный скрипт для Python 3.11+ на стандартной библиотеке. Сторонние зависимости не нужны. Спецификация: [SDD.md](SDD.md).

## Запуск

```sh
git clone https://github.com/amirullov/resource-download-speed.git
cd resource-download-speed
python download_speed.py https://raw.githubusercontent.com/amirullov/resource-download-speed/main/README.md
```

Замените пример URL адресом доступного ресурса. В Windows можно использовать `py -3` вместо `python`, в Linux/macOS — `python3`. URL с параметрами заключайте в кавычки. Для не-ASCII адресов используйте IDNA для домена и percent-encoding для пути. Авторизация в URL не поддерживается. Фрагмент после `#` исключается из запроса.

Справка и проверки:

```sh
python download_speed.py --help
python -m unittest -v
```

Тесты поднимают локальный HTTP-сервер, не требуют внешнего сайта и проверяют число и последовательность загрузок, объём, формулы, редиректы, chunked-передачу, усечение, ошибки, тайм-аут и прерывание.

## Результат

Пример для десяти ответов по 1 MiB при суммарном времени 5 секунд (иллюстрация, не результат реального замера):

```text
Успешных загрузок: 10
Среднее время запроса: 0.500 с
Общий объём: 10485760 байт
Средняя скорость: 2.000 MiB/s
```

Для длительности каждой загрузки `tᵢ` и числа прочитанных байтов `bᵢ`:

- Суммарное время: `T = Σtᵢ`.
- Среднее время: `T / 10` секунд.
- Общий объём: `B = Σbᵢ` байт.
- Средняя скорость: `B / T / 1048576` MiB/s.

1 MiB = 1 048 576 байт. MiB/s — мебибайты в секунду, не мегабиты. Скорости отдельных запросов не усредняются. При неположительном суммарном времени выводится ошибка. Округление до трёх знаков применяется только при выводе.

## Поведение и ограничения

Выполняются ровно 10 последовательных успешных логических GET-загрузок, без прогрева, повторов и параллельности. Тело читается блоками по 64 KiB, не сохраняется в памяти целиком и не записывается на диск. В объём входят фактически прочитанные байты тела, без заголовков, TLS и служебных данных передачи.

Таймер включает соединение, TLS, редиректы, ожидание заголовков и полное чтение тела. Подготовка запроса, закрытие ответа и вывод исключены.

- **Редиректы:** стандартная обработка urllib; HTTP-обращений может быть больше десяти. Учитывается только тело конечного ответа, время переходов включается.
- **Сжатие:** отправляется `Accept-Encoding: identity`. Если сервер всё же вернул сжатое тело, считаются сжатые байты; автоматической распаковки нет.
- **Тайм-аут:** 30 секунд на блокирующую сетевую операцию, а не на всю загрузку. Постепенно поступающий ответ может читаться дольше.
- **Полнота:** корректный применимый Content-Length сверяется с фактическим счётчиком. Для chunked-передачи завершение проверяет библиотека. Без известной длины при завершении соединением отличить усечение от штатного конца невозможно.
- **Ошибки:** при первой ошибке процесс останавливается, в stderr выводится номер загрузки и причина. Успешный итог в stdout появляется только после всех десяти загрузок.

Коды выхода: `0` — успех или справка; `2` — неверные аргументы; `1` — ошибка загрузки или измерения; `130` — Ctrl+C во время замера.

Измеряется скорость конкретного ресурса в текущих условиях, а не предельная скорость интернет-канала. Сервер, кеши, прокси и сеть влияют на результат; специально их влияние не устраняется.

## Итоговая проверка

На 18 ноября 2026 года выполнены 16 автоматических проверок на Python 3.14 в Windows. Проверены потоковое чтение блоками 64 KiB, границы таймера, последовательность, подсчёт байтов, формулы и остановка при ошибках. Минимальная целевая версия — Python 3.11; отдельно на ней проверки не запускались.

Проведены успешные запуски с 10 загрузками локального ресурса, HTTP-страницы example.com и HTTPS-файла README на raw.githubusercontent.com. Скорость зависит от условий запуска и не является критерием приёмки.

Если HTTPS-запуск сообщает `CERTIFICATE_VERIFY_FAILED`, скрипт останавливается с кодом 1. Это означает, что Python не смог проверить цепочку сертификатов конкретного соединения. Проверьте дату компьютера, цепочку сертификатов сервера и доверенные сертификаты вашего окружения или прокси. Проверка TLS в скрипте включена; отключать её для получения результата не требуется. В текущем окружении example.com по HTTPS дал такую ошибку, а HTTPS-запуск с GitHub завершился успешно.
