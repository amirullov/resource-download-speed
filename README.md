# Измерение скорости загрузки ресурса

Консольный скрипт на Python 3.11+ без сторонних зависимостей.

## Статус

Подготовлена спецификация. Реализация и проверки ещё не выполнены.

## Требования

10 последовательных успешных GET-загрузок указанного HTTP/HTTPS-ресурса, потоковое чтение блоками 64 KiB и тайм-аут сетевых операций 30 секунд. Результат: среднее время запроса, фактически прочитанный объём и средняя скорость в MiB/s. При первой ошибке замер останавливается без повторов.

Полный контракт и критерии приёмки: [SDD.md](SDD.md).
